# One-week role-aligned learning plan

This project is a practical scaffold, not proof of mastery. Work through the code and be able to explain every part.

| Day | Focus | Evidence you should produce |
|---|---|---|
| 1 | JavaScript fundamentals, React components, props and state | Explain component tree, props, state and event handlers |
| 2 | React Native core components, styling, Expo and navigation | Run app on Android/Expo Go; explain navigation |
| 3 | Search, filters, lists, keys and reusable components | Extend catalogue and handle empty/loading states |
| 4 | Cart state, derived totals and form validation | Explain state updates and quantity edge cases |
| 5 | HTTP, REST, JSON, async/await, fetch and error handling | Implement a mock API client and explain status codes |
| 6 | Authentication concepts, token safety, Git, debugging and device testing | Explain secure vs insecure storage; test on device |
| 7 | Refactor, README, architecture walkthrough and demo recording | Deliver a clean GitHub repo and a 2-minute walkthrough |

## Interview preparation prompts
1. Why use React Native instead of a WebView?
2. What is the difference between state and props?
3. How does a REST API differ from a normal function call?
4. What are GET, POST, PUT/PATCH and DELETE used for?
5. How do you represent loading, success, empty and error states?
6. Why should secrets and raw passwords not be stored in source code?
7. How would you test an order flow on an Android device?
8. What would you do if an API request fails or returns invalid JSON?
